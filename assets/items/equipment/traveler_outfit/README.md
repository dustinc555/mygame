# Traveler hide outfit

Four independently equipped items: **Traveler Leather Jacket** (chest), **Traveler Hide Trousers** (legs), **Traveler Hide Boots** (feet), **Traveler Hide Gauntlets** (hands). Warm brown worked-hide jacket with darker reinforcement, gray-brown relaxed trousers with reinforced knees, darker calf-high laced boots with rounded feet and low soles, and full-finger gauntlets with tapered forearm guards, bound rims and leather lacing. Each item has **one authored clothing model**, adapted by the shared wardrobe to registered bodies. Body geometry remains visible.

## Where to edit

Open **`source/male_regular.blend`** in Blender. This is the active source for all four garments: one rig, a hidden matching reference body and the garments at the production origin, with images packed. Author against this reference once; do not maintain male/female or regular/heroic/teen garment copies. The other body-named Blender files and GLBs, including `_original` files, are historical references, not selected runtime fits. Preserve them; do not propagate new edits into them.

Use the Outliner to select `Traveler_Hide_Jacket`, `Traveler_Hide_Trousers`, `Traveler_Hide_Boots` or `Traveler_Hide_Gloves`. Edit the garment, not the reference body or rig rests. Jacket rear armhole panels continue beneath the outer sleeve. Preserve the gloves' authored individual finger weights; shared fitting does not replace their animation weights with the wearer's. Keep boot sole, upper and seam changes together.

The gauntlets retain the existing `traveler_hide_gloves` item ID and source paths. Their forearm guards have a complete tapered cut with movement room, not a shape molded around the jacket. The unchanged sleeve covers most of the guard; removing the jacket reveals the finished cuff and lacing. The hand/guard boundary is welded, the obsolete short-glove wrist trim is removed, and local thumb-side wrist room closes the large idle wrist gaps without changing finger weights. Do not enlarge the gauntlets or squeeze the jacket to force the reverse layering.

The regular male trousers' rear center seam blends both thigh weights with the pelvis so it bridges the seat during deep bends, rather than following one inward body surface. Preserve this local blend and its small seam allowance when editing; inspect the complete `Farm_Harvest` cycle from the rear as well as Idle and Walk. This is authored skinning/geometry, not an animation-specific runtime correction.

In the Material Properties / Shader Editor, each garment's leather materials contain packed base-color, roughness and normal images. The `Traveler finish Leather color` image node owns the visible color; `Traveler finish Leather roughness` supplies roughness through its green channel. Normal Map strength is 0.28 for the jacket, 0.24 for trousers and 0.20 for boots/gauntlets. Jacket/boot/glove roughness is centered near 0.55/0.53/0.57; trousers remain more matte at 0.70. Keep the restrained grain, broad panel contrast and subtle leather sheen, rather than cloudy blotches or uniform noisy distress. Tiny stitching, trim and hardware retain separate solid materials. Re-export only the affected garment's source after an art edit; these are Blender authoring controls, not live runtime sliders. Preserve the authored cut and movement room.

Footwear grounding is shared production behavior in `features/actors/projection/humanoid/humanoid_body_projection.gd`, using cached posed sole samples from `footwear_support_samples.gd`. It lifts the visual only when a supported sole penetrates a physical floor, with 2 mm clearance and an 18 cm maximum correction. It does not reshape boots or move the collision actor. New shoes use the same path automatically. This is not independent-foot IK: uneven ground can leave one foot above the lower surface. Test actual World1 idle/walking, slopes, equipment removal and body sliders; an Outfitter floor alone does not prove gameplay contact.

## Inventory and shop icons

Each of the four item resources uses a transparent PNG beside its source asset, named after the item ID. These are saved renders of the actual source meshes and materials, not live 3D previews. The original SVGs remain available as alternatives. Change **ItemDefinition → Icon** to select the image; the normal inventory, equipment, drag and shop controls all read that field.

When refreshing the pictures after a model change, render only the garment on a transparent background with neutral lighting. Pose the jacket sleeves downward and arrange boots/gauntlets together in the disposable thumbnail scene; never save those presentation transforms into the worn equipment. Frame all visible parts with a small transparent border, retain their proportions, and inspect at normal inventory and shop sizes. Icon regeneration is an authoring step, not an automatic runtime rebuild.

## How the fit is selected

Each traveler item under `features/inventory/resources/items/` has one `EquipmentVisualDefinition` in `equipped_visuals`: `visual_scene` selects the source below and `clothing_binding` selects its generated binding. These items no longer use `body_fits`. The human archetypes own `wardrobe_profiles`, mapping each actual body-scene path to its shared body registration. `ClothingFitter` generates disposable wearer meshes for the actor and character editor; changing body/build changes the target profile, not the authored clothing model.

Active source exports:
- jacket: `assets/items/equipment/traveler_leather_jacket/body_fits/male_regular.glb`
- trousers: `assets/items/equipment/traveler_trousers/male_regular.glb`
- boots: `assets/items/equipment/traveler_hide_boots/male_regular.glb`
- gloves: `assets/items/equipment/traveler_hide_gloves/male_regular.glb`

The jacket's `body_fits/` directory name is historical; only the listed source is selected. Generated bindings live in `assets/items/equipment/wardrobe_bindings/`. In `tools/wardrobe/manifest.json`, trousers use `clearance_ratio = 0.002`; gauntlets, jacket and boots use `0.0`. The gauntlets' previous hand clearance is baked into their source geometry; their guard has modeled movement room. Do not add the old normal offset again: it would also inflate the fine laces and stitching. Source-reference clearance is not a target-height inflation or universal collision guarantee.

This outfit uses the six registered human male/female regular, heroic and teen bodies. Height, shoulder, arm and neck sliders deform the live skeleton and its clothing without refitting every frame. Future mesh-morph sliders need body-owned deformed cage input and cache invalidation; they are not automatically supported. The gauntlet wrist repair is not complete hand-fit acceptance: female regular little-finger and female heroic thumb/palm skin still protrude. The female regular body registration shortens the little-finger correspondence; that shared-data defect remains unresolved, not something to conceal by enlarging the garment. Separate jacket, boot and layering intersections also remain, including the unchanged jacket's female heroic elbow in the folded-arms pose; other-race fit and arbitrary combinations are not guaranteed. Legacy hands-slot items containing entire sleeves are not compatible with this jacket. Equipping does not change anatomy or the game-default body selection.

## Adding or changing a garment

1. **Approve the look first.** Start with one garment on one body and show the complete outfit early. Keep a recoverable previous source. Minor clipping is preferable to swollen clothes or hip protrusions.
2. **Fit that garment deliberately.** Preserve its cut, seam placement and natural room. These trousers remain full-length, with cloth outside the boot and an ankle hem overlapping the footwear. Never squeeze the cloth inside the calf or remove lower-leg coverage to make one boot combination look clean. Correct local intersections and demonstrated weight mismatches; do not expand the entire garment to cover every pose. Keep crotch, heel, finger and armhole weights tied to the correct side and joint.
3. **Check independent pieces and actual motion.** Use the production `tools/outfitter/outfitter.tscn`, **Human → Sex / body → Build**. Search `Traveler`, equip the outfit, then remove the boots: the trousers must still cover both calves continuously. Swap other footwear, remove the trousers while retaining boots, and check gloves without the jacket. Use the Animation dropdown and drag to orbit. Inspect front, side and rear in Idle, Walk, Jog_Fwd, Idle_FoldArms, an attack, Farm_Harvest and Sitting_Idle. Check seat/waistband, rear armholes, closed fingers, heels and boot/trouser overlap. Recheck affected body variants, not only the first successful one. The normal selectors retain the outfit and animation; do not add a parallel preview catalog.
4. **Export only garment + matching rig.** Export GLB from the active scene, selected objects, skins enabled, animations disabled, +Y up. Keep the body reference out of the export. Triangulate an export copy if editing quads; retain editable topology in Blender. Check for normalized skin weights, no unweighted vertices and no reference meshes.
5. **Rebuild the one binding.** Enable `skins/use_named_skins`, disable animation import and embed images using Basis Universal compression. Targeted-reimport the source, then run `python3 tools/wardrobe/author.py build --garment <id>` and `python3 tools/wardrobe/author.py verify --garment <id> --fresh-native`. Use the manifest IDs `traveler_leather_jacket`, `traveler_trousers`, `traveler_hide_boots` or `traveler_hide_gloves`. For a new item, follow `tools/wardrobe/README.md`: one manifest entry and one shared visual/binding, `surface_offset_ratio = 0.0`, no body replacement slots or per-body garment map.
6. **Reload the saved item.** Equip, change sex/build, exercise slider extremes, and unequip through the actual actor and character editor. Confirm generated clothing follows the selected body and anatomy stays visible. Run `./tests/run.sh` and `./tests/run.sh validation --filter equipment_body_fits`; then regenerate the dependency graph per `AGENT.md`. Technical tests do not replace source-cut, Idle/Walk, bend and layering review. Cold fitting still has a cost; cached reuse is not a promise of instant first equip.

## Provenance

Project-authored garment shapes, panels, seams, closures and hide treatment, fitted against copies of Quaternius Universal Base Characters already attributed in the project. Glove topology and local articulated jacket panels derive from those reference bodies. Purchased/vendor sources are untouched. The earlier detailed leather jacket artwork remains in its original asset directory; it is not the active outfit source. `source/.gdignore` keeps editable Blender files out of automatic Godot imports.
