# Character Creation Demo

Use this to test the dedicated character creation flow without routing through a barber.

1. Open `res://scenes/test_levels/character_creation_demo.tscn`.

2. Run the scene.

3. The full-screen character creator opens automatically.

4. Creation mode exposes `Name`, `Race`, `Sex`, `Skin color`, `Height`, `Shoulders`, `Head`, and body-specific hair/beard controls. `Race` only offers `Human` for now.

5. Press `Save` to spawn the created character at `CharacterSpawn`.

6. Confirm the spawned character is selected and starts with peasant clothes, an iron sword, a round shield, and 10 silver.

7. Pressing `Cancel` should close the creator without spawning another character.
